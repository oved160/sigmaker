How to install your signature
Gmail
Settings → See all settings → General → Signature → Create new. Click Copy signature above and paste into the box.
Outlook (web / new Outlook)
Settings → Mail → Compose and reply → Email signature. Paste with Copy signature.
Apple Mail
Settings → Signatures → +. Untick “Always match my default message font”, then paste.
Other clients
If your client accepts raw HTML, use Copy HTML or Download .html.

SigMaker runs in your browser. No accounts, cookies, or analytics — the only thing ever uploaded is an image you choose to host.
